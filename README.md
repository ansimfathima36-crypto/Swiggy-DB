# 🍔 Swiggy SQL Database Project
## 📌 Project Overview

This project is a MySQL-based Swiggy food delivery database designed to manage and analyze data related to customers, restaurants, menu items, orders, deliveries, payments, delivery partners, and customer reviews.

The project demonstrates practical SQL skills including database design, table creation, primary keys, foreign keys, constraints, indexes, and data analysis queries.

## 🗂️ Database Structure

The database contains the following tables:

- Customers – Customer personal and registration details
- Restaurants – Restaurant information, cuisine, location, and ratings
- MenuCategories – Food category details
- MenuItems – Restaurant menu items, prices, and availability
- Orders – Customer orders and order status
- DeliveryPartners – Delivery partner details
- Delivery – Delivery assignment and delivery status
- Payments – Payment methods, status, and transaction details
- Reviews – Food and delivery ratings with customer feedback

## 🚀 How to Run
1. Open MySQL Workbench.
2. Open the SWIGGY(1).sql file.
3. Execute the script.
4. The SwiggyDB database will be created.
5. Use the database and run SQL queries for analysis.
